# IPSW Firmware Guide

Free guide to download IPSW firmware files for iPhone, iPad and Mac.

## What is an IPSW file?

An IPSW file is the firmware package Apple uses to restore or update iOS, iPadOS and macOS devices.

## Download IPSW Files

You can find signed and unsigned IPSW files for all Apple devices here:

[IPSW.io - Download IPSW Files](https://ipsw.io)

## How to Restore with IPSW

1. Download the IPSW file for your exact device model.
2. Connect your device to your computer.
3. Open Finder (Mac) or iTunes (Windows).
4. Hold Option (Mac) or Shift (Windows) and click Restore.
5. Select the IPSW file and wait for it to finish.
